# SawaFlix: Designer & UX Guide (Sprint 1)

Welcome, Kingsley! As the lead designer, your goal is to make SawaFlix look premium, professional, and culturally authentic. You define the "Look and Feel" that the developers build.

---

## 🎨 Beginner's Design Roadmap
Design is not just about "pretty colors"—it's about how the user *feels* while using the app.

### Phase 1: Mastering Figma
- **Introduction to Figma**: [Official Tutorial](https://www.figma.com/resource-library/figma-for-beginners/) (Learn how to use frames, auto-layout, and components).
- **Design Systems**: [Figma Design Systems](https://www.figma.com/design-systems/) (How to create a library of buttons/colors so everything looks the same).

### Phase 2: UX & Cultural Authenticity
- **Mobile-First Design**: [What is Mobile-First?](https://www.uxpin.com/studio/blog/mobile-first-design/) (Why we design for the phone before the computer).
- **Color Theory**: Use colors that represent Cameroon (Deep greens, vibrant yellows, earth tones) while keeping a "Sleek/Glassmorphic" modern feel.

---

## 🚀 Step-by-Step Task Breakdown

### 1. Role Selection UI
**Goal:** Make it easy for users to choose their path.
- **Visuals**: Create a screen with two large, clear options: "I am a Viewer" and "I am a Creator."
- **Imagery**: Use professional icons or photos that represent the 5 creator categories (e.g., a storyteller under a tree, a musician with an instrument).
- **Hover States**: Design what happens when a user touches or hovers over a role.

### 2. The Verification Wizard (5 Steps)
**Goal:** Make a long form feel like a journey, not a chore.
- **Step 1-4**: Design simple, clean input fields. Don't crowd the screen.
- **Step 5 (Summary)**: This needs to look very "Official." Use a card layout to summarize their data before they submit.
- **Progress Bar**: Design a beautiful bar at the top that shows "Step 2/5" so they know how much is left.

### 3. Admin Dashboard
**Goal:** Efficiency for the SawaFlix staff.
- **The Queue**: Design a list where "Pending" submissions stand out.
- **Review Screen**: Make the documents (IDs, Letters) easy to read. Create a "Full Screen" preview mode.

---

## 📈 Quality Control (Your Superpower)
You are the final judge of quality.
1.  **Developer Review**: On Friday, go to the live site. Does the button look exactly like your design? Is the spacing right?
2.  **Bug List**: If a developer missed a detail, create a "Bug" in the GitHub project board and assign it to them.
3.  **Accessibility**: Make sure the text is large enough for everyone to read, especially for our village elders!
